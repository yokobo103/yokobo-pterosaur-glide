# 翼竜滑空 — 遊べる縦切り

**面白さの仮説（1文）**

> 遠くの上昇気流を見つけて乗り継ぎ、落ちるはずだった場所より先へ行けたとき嬉しい。

灰色の箱。本番の翼竜モデル・植生・音楽は使っていない。この仮説だけを確かめる。

## 遊ぶ

**公開URL: https://yokobo103.github.io/yokobo-pterosaur-glide/**

手元で動かす場合:

```
npm install
npm run dev     # http://localhost:8141
```

- 操作は**左右だけ**。`←` `→`（`A` `D`）、スマホは画面の左半分／右半分を押しっぱなし
- 押している間だけ曲がる。速度は自動（傾けると勝手に減速する）
- 上がる空気の場所は**舞い上がる土ぼこりの柱**で分かる。数字も矢印も出さない
- ところどころに**越えられない高い山**がある。回り込む
- 翼竜は本物のモデル（RH02）、カメラは後ろ約5m。`?size=2|3` は比較用
- 木と岩はAstraの氾濫原の原型（遠くは代わりの形）。ところどころの高い山は火山。`?notrees` で木なし
- 既定は丘のある世界。`?world=flat` で起伏なし、`?world=ridge` で尾根の風の試作
- 右の帯と音が上昇率。芯に近いほど高く速く鳴る
- 日が傾くと空気は上がらなくなる。降りたところが記録
- `?seed=17` で同じ地形を再現。`R` またはダブルタップでやり直し

## なぜこの形になったか（測って決めた）

| 決めたこと | 根拠 |
|---|---|
| 制限時間を置かない | 20分の時計を置くと全戦略が3〜4kmに潰れた（差12%）。無制限だと2.97km→11.06km（3.7倍） |
| 代わりに日没で終わらせる | 無制限＋無限の場だと上手いほど落ちず、281km・7時間飛び続けて走行が終わらなかった |
| 操作は左右だけ | 速度操作を足しても上限は11.06kmのまま動かず、下限だけ3.53km→2.22kmに落ちた。難しさだけ増えて面白さは増えない |
| 上昇率を音で出す | 芯から80mずれると300m上がるのに16.6分（芯なら3.3分）、100mずれると上がれない。今どれだけ上がっているか分からないと左右の操作が運になる |
| 上昇気流の外は沈む | これが無いと素通りするだけで高度が増え、直進でも7.3km出てしまい「見送る」に代償が無くなった |

測定の詳細は `docs/FINDINGS.md`。

## 構成

```
src/world.js    地形と上昇気流。ブラウザにもNodeにも依存しない純JS
src/flight.js   飛行と自動操縦。左右の入力(-1..1)だけを受ける
src/scene.js    three.js の描画
src/audio.js    上昇率の音
src/main.js     入力・ループ・検査用の口(window.__slice)
tools/tune.mjs   ブラウザなしで縮尺を詰める
tools/capture.mjs 実ブラウザで飛ばして絵と数字を取る／本物のタッチで指の検査
tools/sheet.mjs   撮った絵を1枚に並べる
```

**地形は運ばない。** 川の距離場・堤・段丘・種つきノイズの関数で、その場で作る。上昇気流もチャンク単位で必要になったときに湧く。だから場は無限で、転送量はゼロ。

## 縮尺（`src/world.js` の TUNE と `src/flight.js` の AIR）

| | 値 | 効く先 |
|---|---|---|
| 滑空比 | 13.0（沈下こみ10.8） | 1本の柱から次へ届く距離 |
| 上昇気流 | 間隔900m / 強さ5.5〜11.0 m/s / 半径110〜185m | 選択肢の数と、旋回の難しさ |
| 雲底 | 地面から150〜280m | 1本あたりの滞在時間 |
| 外の沈下 | 0.75 m/s | 見送ることの代償 |
| 日没 | 720秒 | 1走行の長さ |

`npm run tune` で、この縮尺での自動操縦の成績が出る。

## 検査

```
npm run build && node tools/run-checks.mjs   # 全部の検査を1回で(開発サーバー不要)
node tools/run-checks.mjs --public           # 公開版
npm run dev              # 別で起動しておく
node tools/capture.mjs --touch      # 手元
node tools/verify-public.mjs        # 公開URLが本当に飛べるか
```

- PC / スマホ の両サイズで、要所5場面の絵
- 実プレイ状態での描画コマ数
- **本物のタッチ**で左半分／右半分／左右同時の3件
